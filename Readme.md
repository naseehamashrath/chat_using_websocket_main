           Room-Based WebSocket Chat App

A simple real-time chat application built using WebSockets, where users can:

 Join rooms by ID

 Send and receive real-time chat messages

 See when others are typing

 Lightweight and fast with no external database

 Built with React (frontend) and Node.js + TypeScript (backend)

                      Features

 Join any room using a Room ID

 Real-time message broadcasting within rooms

 Typing indicator ("Someone is typing...")

 System messages when users join/leave

 Clean and modular CSS

 Auto-scrollable chat window

 Fully functional without a database
